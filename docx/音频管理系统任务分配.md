# HAUT 音频管理系统 - 工作分配总结

## 1. 于子桐 (kaifeng) - 全栈开发 & 前端主导

### 安全与认证模块

- **JWT 工具类开发 (`JwtUtil.java`)**
    - Token 生成与解析
    - 密钥外部化配置（从 `application.yml` 读取）
- **JWT 拦截器实现 (`JwtInterceptor.java`)**
    - Token 验证逻辑
    - 角色信息提取并注入请求属性
- **Web 配置类 (`WebConfig.java`)**
    - 注册 JWT 拦截器
    - 配置排除路径（登录接口、音频流接口）
- **认证控制器 (`AuthController.java`)**
    - 用户登录接口
    - 用户注册功能
    - 用户管理 CRUD（增删改查）
    - 权限控制验证

### 前端开发

- **完整前端界面 (`index.html`)**
    - 现代化 UI 设计（侧边栏导航、渐变背景）
    - 登录页面与主应用分离
    - 三大功能板块：音频乐库、上传音频、用户管理
- **用户交互功能**
    - 拖拽上传支持
    - 上传进度条显示
    - 文件信息展示
    - 分页控件
    - 音频播放错误处理
- **权限控制前端实现**
    - 管理员/操作员角色区分
    - 动态显示/隐藏操作按钮
    - 用户管理界面（添加、编辑、删除用户）
- **用户体验优化**
    - 空状态提示
    - 加载失败提示
    - 操作成功/失败反馈

### 其他贡献

- 配置文件优化
- 文档维护

## 2. 阚德扬 (kdy) - 后端核心业务开发

### 音频管理核心功能

- **音频控制器 (`AudioController.java`)**
    - 音频上传接口（带权限验证）
    - 音频列表分页查询
    - 音频删除接口（仅管理员）
    - 音频名称修改接口（仅管理员）
    - 音频流式播放接口
    - 音频状态检查接口
    - 无效记录清理接口
- **音频服务层 (`AudioService.java`)**
    - 文件上传逻辑（UUID 命名、格式验证）
    - MD5 哈希计算（从文件计算避免内存溢出）
    - 分页查询（按创建时间降序）
    - 物理+逻辑删除同步
    - 音频名称修改
    - 无效记录清理功能
    - 文件存在性验证
- **实体类与 Mapper**
    - `AudioAsset` 实体类（雪花算法 ID、JSON 序列化配置）
    - `AudioAssetMapper` 数据访问层

### 技术优化

- **文件存储优化**
    - 使用 `Files.copy` 替代 `transferTo`
    - 路径规范化防止穿越攻击
    - 目录自动创建
- **删除逻辑改进**
    - 先保存文件路径再逻辑删除
    - 检查结果验证
    - 异常处理完善
- **日志系统**
    - 详细的操作日志输出
    - 错误追踪信息

## 3. 杨硕 (ysh) - 基础设施 & 数据库

### 数据库设计与配置

- **数据库表结构设计**
    - `audio_assets` 表（音频资产）
    - `sys_users` 表（系统用户）
    - 初始化测试数据（管理员、操作员账户）
- **MyBatis-Plus 配置**
    - 分页插件配置 (`MybatisPlusConfig.java`)
    - 逻辑删除配置
    - 驼峰命名映射
    - SQL 日志输出
- **应用配置文件 (`application.yml`)**
    - 数据源配置
    - 文件上传大小限制
    - 存储路径配置
    - JWT 密钥与过期时间配置
    - 数据库初始化模式

### 项目基础设施

- **Maven 依赖管理 (`pom.xml`)**
    - Spring Boot 3.2.5 版本选择
    - MyBatis-Plus Spring Boot 3 专用 Starter
    - JWT 依赖（`jjwt-api`/`impl`/`jackson`）
    - MySQL 驱动
    - Lombok 支持
- 项目启动类
- Schema 初始化脚本 (`schema.sql`)

### 安全策略

- 存储路径外部化配置
- 防止路径穿越的基础架构支持
