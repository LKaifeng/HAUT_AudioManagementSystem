# 1. 在前端界面中添加一个登录按钮，当用户点击登录按钮时，会弹出一个登录框，用户输入用户名和密码，点击登录按钮后，会发送一个POST请求到后端服务器，请求体中包含用户名和密码。
# 2. 后端服务器接收到请求后，会验证用户名和密码是否正确，如果正确，会生成一个JWT（JSON Web Token），并将JWT返回给前端服务器。
# 3. 前端服务器接收到JWT后，会将JWT存储在本地存储中，以便在后续请求中使用。
# 4. 在前端界面中添加一个导航栏，当用户点击导航栏中的某个链接时，会发送一个GET请求到后端服务器，请求头中包含JWT。
# 5. 后端服务器接收到请求后，会验证JWT是否有效，如果有效，会返回相应的数据，否则会返回一个错误信息。
